1. 한 줄 소개 - 무엇을 왜 만들었나 [작성자 : 신강현]

스마트 소화기 위치 안내 받침대

화재 발생 시 LED 점멸과 부저 경보를 통해 소화기 위치를 신속하게 안내하여 초기 대응 시간을 단축하고, 기존 소화기를 교체하거나 개조하지 않고도 안전성을 향상시키기 위한 스마트 소화기 위치 안내 시스템입니다.

2. 시스템 블록도 - 입력 → 판단 → 출력 → 표시 [작성자 : 송은찬]<br/>

| 단계 | 구분 | 세부 내용 |
| :---: | :---: | :--- |
| **1. 입력** | 비상·초기화 버튼 | 비상 입력용 푸시버튼 / 정지·초기화 버튼 |
| **2. 판단** | Arduino UNO | 비상 신호 감지 · 상태 판단(대기 / 경보 / 초기화) · 경보 제어 및 오입력 방지 |
| **3. 출력** | 시각 + 청각 | LED 점멸(시각 안내) + 부저 경보(청각 안내) |
| **4. 표시** | 상태 확인 | 시리얼 모니터 상태 표시(대기 / 경보 / 초기화) |

| 부품명 | 사용 목적 |

6. 트러블슈팅 — 막혔던 문제 1~2개와 해결 [작성자 : 김상현]
   
 ### 문제 1. 소화기 위치 안내 방법

- 문제 : 화재 발생 시 주변이 어둡거나 연기가 많으면 소화기의 위치를 찾기 어려울 수 있다.
- 해결 방안 : LED 점멸과 부저를 함께 사용하여 시각과 청각으로 소화기 위치를 알 수 있도록 설계하였다.

### 문제 2. 기존 소화기 활용 방법

- 문제 : 기존 소화기를 직접 개조할 경우 설치 및 관리에 어려움이 있을 수 있다.
- 해결 방안 : 소화기 자체를 개조하지 않고 받침대에 LED와 부저를 설치하는 방식으로 설계하였다.
