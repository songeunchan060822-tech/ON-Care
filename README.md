1. 한 줄 소개 - 무엇을 왜 만들었나 [작성자 : 신강현]

스마트 소화기 위치 안내 받침대

화재 발생 시 LED 점멸과 부저 경보를 통해 소화기 위치를 신속하게 안내하여 초기 대응 시간을 단축하고, 기존 소화기를 교체하거나 개조하지 않고도 안전성을 향상시키기 위한 스마트 소화기 위치 안내 시스템입니다.

2. 시스템 블록도 - 입력 → 판단 → 출력 → 표시 [작성자 : 송은찬]
   [비상 버튼 입력 / 초기화 버튼 입력]
        │
        ▼
  [Arduino UNO]
  비상 신호 감지
  상태 판단 (대기 / 경보 / 초기화)
  경보 제어 및 오입력 방지
          │
    ┌─────┴─────┐
    ▼           ▼

  (시각 안내) (청각 안내)
          │
          ▼
  시리얼 모니터 상태 표시
  (대기 / 경보 / 초기화)
